# Git Course

Static site with lessons and examples for learning Git. This repository contains HTML and CSS files that demonstrate Git concepts and workflows.

## How to view
Open `index.html` in a browser or serve the directory with a local server:

`python -m http.server 8000`

## Files
- `index.html` — course content and navigation
- `style.css` — styles for the site
